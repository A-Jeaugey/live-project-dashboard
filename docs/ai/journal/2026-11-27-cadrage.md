## Constats

- Le projet GitLab du jeu ne contient qu'un commit : ni labels, ni jalons, ni issues, ni `docs/`, ni CI.
- Le token fourni avait toutes les portées, écriture comprise. Aucune écriture n'a été faite. Son remplacement par
  un token `read_api` est recommandé.
- Contradiction relevée dans le cahier des charges : le bouton « Je prends » sous les notifications n'est possible
  que si le bot publie lui-même ces notifications, ce qui ferait doublon avec l'intégration native de GitLab
  (voir D-012).
